# Apexer

A dark Omarchy theme with a muted olive accent and warm sand highlights.

## Install

```bash
omarchy-theme-install https://github.com/anuj-kosambi/omarchy-apexer-theme
```

## Contents

- `colors.toml` — palette (dark mode)
- `icons.theme` — Yaru-red icon set
- `backgrounds/` — wallpaper
